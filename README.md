# Laboratorio #10: Programación Orientada a Objetos y Seguridad en PHP
**Asignatura:** Desarrollo Web - UTP  
**Profesor:** Prof. Victor M. Sarmiento A.

## Instrucciones Rápida
1. Haga un **Fork** de este repositorio.
2. Clone su fork localmente dentro de `xampp/htdocs/`.
3. Cree su rama de trabajo: `git checkout -b lab10-apellido1-apellido2`.
4. Resuelva los ejercicios 1, 2 y 3 completando las zonas marcadas con `// TODO:`.
5. Realice commits frecuentes con las etiquetas `[EJ1]`, `[EJ2]`, `[EJ3]`.
6. Envíe sus cambios a su fork y abra un **Pull Request** hacia el repositorio principal.

*No modifique `autograde.php` ni el archivo de workflow en `.github/workflows/`.*
